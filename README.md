# Pronto Fashion project pack

This folder contains a GitHub Pages ready, single-page project for the NCI Technology for Business final project.

## What's here

- `index.html` — the public landing page and embedded interactive demo. There are no external code or image dependencies.
- `SUBMISSION_CHECKLIST.md` — the parts that still need a real source check, another person's test, publishing and your own reflection.

## Publish on GitHub Pages

1. Sign in to GitHub and create a **public** repository named `pronto-fashion`.
2. Upload `index.html` to the root of the repository. Keep `README.md` and this checklist for your own use; they do not need to appear on the page.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to finish. Your public link should look like `https://YOUR-USERNAME.github.io/pronto-fashion/`.
6. Open that `github.io` link in a private/incognito window, on a phone and laptop. Try the filters and reserve a sample look. Refresh to confirm that the sample reservation remains.

The brief has two inconsistent submission instructions: page 2 says paste a page link and reflection into the Moodle text box, while page 4 asks for one Word/PDF with two links, screenshots and the reflection. The safest course is to follow the live Moodle assignment submission point and include the requested link and your own reflection there. If it accepts a file, attach a PDF with the landing-page link, screenshots and reflection as well.

## Demo behaviour

- 12 made-up sample product records are included, covering women's eveningwear and men's suits, formal shirts, jeans, designer T-shirts and polos, ties and cufflinks.
- Audience, occasion, price and size filters update the results.
- Arrival estimates are calculated from the current time and each sample item's made-up delivery minutes. All sample ETAs are below four hours.
- A sample reservation is saved in browser `localStorage` and restored after refresh. It can be cleared.
- The page sends no form data, takes no payment and creates no real order or delivery.

## Final checks you must complete

1. Open the two official fashion retailer links from the page. Record the date you checked each source and accurately describe its current delivery options for Ireland. Do not claim a retailer cannot deliver within four hours unless its current source supports that claim.
2. Ask one person who did not build the page to try the demo on a phone. Use the checklist to record their task, what confused or failed, and the change you make.
3. Write your own 150–300 word reflective statement. The brief prohibits AI or rewriting tools for this section.
4. Add the actual public `github.io` link and screenshots to Moodle as required by the submission point.

## Project assumptions

Pronto is a fictional student concept, not a live retailer. The initial Dublin customer segment, local stock partnerships, courier fulfilment, example products, inventory, prices, delivery estimates, €5.95 delivery fee and retailer commission are assumptions or sample data. The demo is a booking-flow prototype, not evidence that the proposed service can yet fulfil an order.
